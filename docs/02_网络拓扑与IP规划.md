# 02 · 网络拓扑与 IP 规划

## 一、拓扑设计

采用经典三层园区网络架构，4 台华为 S5700 交换机分属三层：

```
                 [ 宿主机环回适配器 192.168.100.250 ]
                            │ 桥接
                        [ Cloud 云 ]
                            │ Gi0/0/24 (VLAN100)
                      [ SW-Core 核心层 ]        Vlanif100 = 192.168.100.1
                            │ Gi0/0/1 Trunk (10/20/30/100)
                      [ SW-Agg 汇聚层 ]         Vlanif100 = 192.168.100.2
                 ┌──────────┴──────────┐
        Gi0/0/2 Trunk(10/100)   Gi0/0/3 Trunk(20/30/100)
      [ SW-Acc1 接入层 ]        [ SW-Acc2 接入层 ]
      Vlanif100=192.168.100.11  Vlanif100=192.168.100.12
      Gi0/0/2~5 接入 VLAN10/20  Gi0/0/2~4 接入 VLAN20/30
```

### 层次职责

| 层次 | 设备 | 职责 |
|---|---|---|
| 核心层 | SW-Core | 三层网关（承载各 VLAN 的 VLANIF）、上联 Cloud、下联汇聚 |
| 汇聚层 | SW-Agg | 纯二层 Trunk 汇聚，转发接入层到核心层 |
| 接入层 | SW-Acc1 / SW-Acc2 | 下挂终端，按业务 VLAN 划分接入端口 |

## 二、VLAN 规划

| VLAN | 用途 | 网段 |
|---|---|---|
| 10 | 办公网 | 192.168.10.0/24 |
| 20 | 研发网 | 192.168.20.0/24 |
| 30 | 访客/监控 | 192.168.30.0/24 |
| 100 | **管理网** | 192.168.100.0/24 |

## 三、管理地址规划（VLANIF）

管理地址统一配置在管理 VLAN 的 VLANIF 接口上，作为 SSH 连接目标：

| 设备 | 管理地址（Vlanif100） | 角色 |
|---|---|---|
| SW-Core | 192.168.100.1 | 核心层 |
| SW-Agg | 192.168.100.2 | 汇聚层 |
| SW-Acc1 | 192.168.100.11 | 接入层 |
| SW-Acc2 | 192.168.100.12 | 接入层 |
| 宿主机环回适配器 | 192.168.100.250 | 管理终端 |

## 四、端口与链路规划

| 设备 | 端口 | 类型 | 承载 |
|---|---|---|---|
| SW-Core | Gi0/0/1 | Trunk | VLAN 10/20/30/100（连 SW-Agg） |
| SW-Core | Gi0/0/24 | Access | VLAN 100（连 Cloud） |
| SW-Agg | Gi0/0/1 | Trunk | VLAN 10/20/30/100（连 SW-Core） |
| SW-Agg | Gi0/0/2 | Trunk | VLAN 10/100（连 SW-Acc1） |
| SW-Agg | Gi0/0/3 | Trunk | VLAN 20/30/100（连 SW-Acc2） |
| SW-Acc1 | Gi0/0/1 | Trunk | VLAN 10/100（连 SW-Agg） |
| SW-Acc1 | Gi0/0/2~3 | Access | VLAN 10（办公） |
| SW-Acc1 | Gi0/0/4~5 | Access | VLAN 20（研发） |
| SW-Acc2 | Gi0/0/1 | Trunk | VLAN 20/30/100（连 SW-Agg） |
| SW-Acc2 | Gi0/0/2 | Access | VLAN 20（研发） |
| SW-Acc2 | Gi0/0/3~4 | Access | VLAN 30（访客/监控） |

## 五、管理通道可达性

- 管理 VLAN 100 通过 Trunk 打通核心—汇聚—接入三层，4 台设备的 `Vlanif100` 处于同一广播域；
- 宿主机通过 eNSP「Cloud」设备桥接进 VLAN 100（映射到环回适配器 192.168.100.250/24）；
- 因此宿主机可直接 SSH 到 4 台设备的 Vlanif100 地址，实现集中自动化管理。
