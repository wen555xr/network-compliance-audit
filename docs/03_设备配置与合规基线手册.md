# 03 · 设备配置与合规基线手册

本文档说明 4 台设备的配置要点，以及它们各自相对 10 项合规规则的合规/违规情况。
完整配置见 `ensp/configs/*.cfg`（粘贴式配置）与 `automation/compliance/samples/*.cfg`（display 输出）。

## 一、合规梯度设计

为让审计结果有区分度、报告可读，4 台设备刻意配置了不同数量的违规项：

| 设备 | 角色 | 合规率 | 违规规则 | 演示定位 |
|---|---|---|---|---|
| SW-Core | 核心层 | **100%** | 无 | 安全基线标杆 |
| SW-Agg | 汇聚层 | **70%** | R08/R09/R10 | 缺日志与 ACL |
| SW-Acc1 | 接入层 | **60%** | R01/R07/R08/R09 | SNMP 默认串 + HTTP 开启 + 缺日志 |
| SW-Acc2 | 接入层 | **30%** | R01/R03/R04/R05/R06/R07/R08 | 高危重灾区 |

## 二、逐设备配置要点

### SW-Core（核心层，10/10 合规）

- **三层网关**：`Vlanif10/20/30/100` 承载业务与管理网段，管理地址走 `Vlanif100`；
- **AAA + 强口令**：`local-user admin password irreversible-cipher`（不可逆加密）；
- **仅 SSH**：`stelnet server enable` + `protocol inbound ssh`，未开 Telnet/HTTP；
- **SNMP 加密自定义串**：`snmp-agent community read cipher CoreAudit@2024`；
- **日志集中 + 时间戳**：`info-center loghost 192.168.100.250` + `info-center timestamp log date`；
- **管理 ACL**：`acl 2000` 仅放行网管网段，并 `acl 2000 inbound` 应用到 VTY。

### SW-Agg（汇聚层，7/10 合规）

- 纯二层 Trunk，配置与核心类似（AAA/SSH/SNMP 加密均合规）；
- **合规缺口**：未配置 `info-center loghost`（R08）、未配置 `info-center timestamp`（R09）、
  未配置管理 ACL（R10）。

### SW-Acc1（接入层，6/10 合规）

- AAA/密码/SSH/ACL 均合规；
- **合规缺口**：
  - SNMP 仍使用默认只读社区串 `public`（`snmp-agent community read cipher public`，R01）；
  - 开启明文 HTTP 管理（`http server enable`，R07）；
  - 缺日志服务器与时间戳（R08/R09）。

### SW-Acc2（接入层，3/10 合规，高危重灾区）

- **合规缺口（7 项）**：
  - SNMP 默认明文社区串 `public`（R01）；
  - 本地用户密码明文存储 `simple Admin@123`（R03），且为默认弱口令（R04）；
  - 未启用 SSH（R05），反而开启 Telnet（`telnet server enable` + `protocol inbound telnet`，R06）；
  - 开启明文 HTTP 管理（R07）；
  - 缺日志服务器（R08）。
- 仅 AAA 认证（R02）、日志时间戳（R09）、管理 ACL（R10）三项合规。

## 三、SSH 配置要点（eNSP 中）

每台设备启用 SSH 远程管理的标准命令序列：

```
rsa local-key-pair create            # 生成 RSA 密钥对（交互式，回车采用默认）
stelnet server enable                # 启用 STelnet(SSH) 服务
ssh user admin authentication-type password
ssh user admin service-type stelnet  # 指定 SSH 用户
aaa
 local-user admin password ...       # 本地用户口令（建议 irreversible-cipher）
 local-user admin privilege level 15
 local-user admin service-type ssh
user-interface vty 0 4
 authentication-mode aaa
 protocol inbound ssh                # 仅允许 SSH 登录
```

> 说明：eNSP 中 `irreversible-cipher` 需要提供不可逆哈希值；真实联调时可先用
> `local-user admin password cipher <口令>` 配置（display 会显示 `cipher`），审计规则 R03
> 会如实标记其为"可逆加密"不合规——这正是教学点。详见 [06_部署与演示指南](06_部署与演示指南.md)。
