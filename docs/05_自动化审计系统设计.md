## 二、模块职责

| 模块 | 职责 | 关键函数/类 |
|---|---|---|
| `main.py` | 编排：采集→解析→审计→报告→告警；解析命令行 | `main()` |
| `collector.py` | Netmiko 批量 SSH 采集运行配置 | `collect_device()` / `collect_all()` |
| `parser.py` | 正则解析引擎，配置文本结构化 | `ParsedConfig` / `parse_config()` |
| `rules.py` | 规则加载 + 规则引擎（解释 rules.yaml） | `Rule` / `RuleResult` / `check_rule()` |
| `auditor.py` | 逐设备逐规则比对 + 评分 + 汇总 | `DeviceResult` / `AuditReport` / `build_report()` |
| `report_html.py` | 自包含 HTML 报告（合规矩阵 + 修复建议） | `render()` |
| `report_excel.py` | Excel 报告（汇总/明细/不合规清单三 Sheet） | `render()` |
| `wechat_alert.py` | 企业微信机器人 Markdown 告警 | `build_markdown()` / `send()` |
| `mock/mock_device.py` | 伪华为 SSH 服务器（paramiko），离线联调 | `HuaweiMockServer` |

## 三、核心数据模型

### ParsedConfig（parser.py）

把 `display current-configuration` 文本解析为结构化字段：

```python
@dataclass
class ParsedConfig:
    raw_text: str          # 原始文本（规则引擎在此上做正则匹配）
    sysname: str           # 设备名
    vlans: list[str]       # vlan batch
    local_users: list[str] # local-user 行
    snmp_communities: list[str]
    interfaces: dict[str, list[str]]  # 接口名 -> 配置行
    info_center: list[str]
    acl_lines: list[str]
    vty_lines: list[str]
    mgmt_ips: list[str]    # 全部 VLANIF 地址
    mgmt_ip: str           # 管理 VLAN(Vlanif100) 地址
```

### Rule / RuleResult（rules.py）

```python
@dataclass
class Rule:
    id, name, category, severity, check_type, pattern, description, remediation

@dataclass
class RuleResult:
    rule: Rule
    passed: bool
    evidence: list[str]   # 命中的配置行（证据）
```

### DeviceResult / AuditReport（auditor.py）

```python
@dataclass
class DeviceResult:
    name, host, role, parsed, results
    # 派生：pass_count / fail_count / rate / failures / is_compliant / mgmt_ip

@dataclass
class AuditReport:
    generated_at, devices, rules, threshold
    # 派生：total_checks / total_pass / overall_rate / noncompliant_devices /
    #        alert_triggered / top_violations()
```

## 四、数据流

1. **采集**：`main.py` 根据 `--source` 获取 `[(name, host, role, text), ...]`；
2. **解析**：`auditor.audit_device` 调 `parse_config(text)` 得到 `ParsedConfig`；
3. **审计**：`rules.check_all(rules, raw_text)` 逐规则执行，得 `[RuleResult, ...]`；
4. **评分**：`DeviceResult.rate = 通过数 / 规则总数 × 100%`；`AuditReport.overall_rate = 总通过 / 总检查`；
5. **报告**：`report_html.render(report)` 与 `report_excel.render(report, path)` 落盘；
6. **告警**：`report.alert_triggered`（overall_rate < threshold）时 `wechat_alert.send(report, webhook)`。

## 五、容错与可运行性设计

- **单台失败不中断**：采集阶段任一设备连接失败仅记录并跳过，不影响其余设备与报告生成；
- **无 webhook 也能演示**：`wechat_alert.send` 在 webhook 为空时打印告警内容（dry-run）；
- **相对/绝对导入兼容**：核心模块均用 `try/except ImportError` 回退，既支持包导入，
  也支持 `py main.py` 直接运行；
- **报告生成物不入库**：`reports/`、`config.yaml` 均写入 `.gitignore`，示例报告放 `sample_output/`。
