# 06 · 部署与演示指南

## 一、环境准备

### 1. 安装 Python 依赖

```bash
cd automation/compliance
py -3.12 -m pip install -r requirements.txt
```

依赖：`netmiko`、`paramiko`、`PyYAML`、`openpyxl`、`requests`。

### 2. （可选）安装华为 eNSP

仅 `--source ensp` 需要。本项目使用 eNSP V100R003C00SPC100，安装到默认路径即可。

## 二、纯离线演示（最快，无需 eNSP）

```bash
cd automation/compliance
py -3.12 main.py --source files
```

- 读取 `samples/` 下 4 台设备的样例配置；
- 输出 `reports/report_<时间戳>.html` 与 `reports/report_<时间戳>.xlsx`；
- 控制台打印：总体合规率 65%（< 阈值 90%），4 台设备合规率 100% / 70% / 60% / 30%；
- 因低于阈值触发告警，未配置 webhook 时以 dry-run 打印告警 Markdown。

## 三、mock 模式演示（验证 Netmiko SSH 链路）

**终端 A** 启动伪华为 SSH 服务器：

```bash
py -3.12 mock/mock_device.py
```

**终端 B** 通过 SSH 采集并审计：

```bash
py -3.12 main.py --source mock -i inventory.mock.yaml
```

mock 服务器在 127.0.0.1:10001~10004 回放 4 台设备的配置，完整走通
「SSH 登录 → 采集 → 解析 → 审计 → 报告 → 告警」链路。

## 四、eNSP 真实联调

### 1. 创建宿主机环回适配器

eNSP 的「云」设备需桥接到宿主机环回网卡。Windows 下创建步骤：

1. `Win + R` → 输入 `hdwwiz` 回车，打开「添加硬件向导」；
2. 「手动从列表选择硬件」→「网络适配器」；
3. 厂商选 `Microsoft`，型号选 `Microsoft KM-TEST 环回适配器`，完成安装；
4. 打开「网络连接」，给该环回适配器配置静态 IP `192.168.100.250/24`（网关留空）。

### 2. 搭建 eNSP 拓扑

按 [ensp/ENSP搭建指南.md](../ensp/ENSP搭建指南.md) 摆放 4 台 S5700 + 1 台 Cloud，
导入 `ensp/configs/` 下配置，连接线路，启动设备。

### 3. 配置 Cloud 桥接

- 双击 Cloud 设备，增加一个端口映射到上一步创建的环回适配器；
- Cloud 的该端口连到 SW-Core 的 `Gi0/0/24`（VLAN 100）。

### 4. 修改设备清单并运行

编辑 `inventory.yaml`，将 `password` 改为设备实际 SSH 口令，然后：

```bash
py -3.12 main.py --source ensp -i inventory.yaml
```

> **SSH 降级说明**：若 eNSP 的 SSH 密钥协商失败，可临时把 `inventory.yaml` 中各设备
> `device_type` 改为 `huawei_telnet`、`port` 改为 23，并在设备上临时开启 Telnet 联调；
> 但注意这本身即违反合规基线（R06），属演示性降级。

## 五、企业微信告警配置

1. 在企业微信群中添加「群机器人」，复制 Webhook URL（形如
   `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx`）；
2. 复制配置模板并填入：

```bash
cd automation/compliance
cp config.example.yaml config.yaml
# 编辑 config.yaml：填入 threshold 与 wechat_webhook
```

3. 运行审计，当总体合规率 < `threshold` 时自动推送 Markdown 告警。

> `config.yaml` 已被 `.gitignore` 忽略，webhook 不会泄露到 GitHub。

## 六、生成示例报告到 sample_output

```bash
py -3.12 main.py --source files --output-dir ../../sample_output
```

## 七、常见问题

| 问题 | 处理 |
|---|---|
| `UnicodeEncodeError` 打印报错 | 控制台为 GBK 编码，告警/报告均以 UTF-8 落盘，不受影响 |
| mock 模式连接超时 | 确认 mock_device.py 已启动、端口未被占用 |
| eNSP SSH 连不上 | 检查环回适配器 IP、Cloud 桥接、设备 SSH 配置与清单口令 |
| Excel 无法打开 | 确认已安装 openpyxl：`py -3.12 -m pip install openpyxl` |
